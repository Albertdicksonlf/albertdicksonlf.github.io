# Escore de Glasgow-Blatchford

> [!abstract] O que é?
> Escore **pré-endoscópico** da [[Hemorragia Digestiva Alta]] que estima a necessidade de intervenção hospitalar (transfusão, terapia endoscópica, radiologia intervencionista, cirurgia) ou morte. Usa só dados da chegada — não precisa da EDA. Seu uso de ouro é **identificar quem pode ir para casa**.

## 🖐️ Técnica de Exame (Como fazer?)
1. **Posicionamento:** à admissão, antes da EDA, com sinais vitais e o primeiro hemograma e ureia.
2. **Ação:** somar os pontos (0 a 23):

| Marcador | Faixa | Pontos |
|:---|:---|:---|
| **Ureia** (mmol/L · mg/dL) | 6,5–7,9 · ~39–47 | 2 |
| | 8,0–9,9 · ~48–59 | 3 |
| | 10,0–25,0 · ~60–150 | 4 |
| | > 25 · > 150 | 6 |
| **Hb — homem** (g/dL) | 12,0–12,9 | 1 |
| | 10,0–11,9 | 3 |
| | < 10,0 | 6 |
| **Hb — mulher** (g/dL) | 10,0–11,9 | 1 |
| | < 10,0 | 6 |
| **PAS** (mmHg) | 100–109 | 1 |
| | 90–99 | 2 |
| | < 90 | 3 |
| **Outros** | FC ≥ 100 | 1 |
| | [[Melena]] | 1 |
| | [[Síncope]] | 2 |
| | Doença hepática | 2 |
| | Insuficiência cardíaca | 2 |

*A ureia do escore é a ureia britânica em mmol/L (não o BUN). Conversão para o laboratório brasileiro: mg/dL ≈ mmol/L × 6.*

3. **Critério de Positividade:**
	- **0–1 → muito baixo risco:** candidato a manejo ambulatorial com EDA eletiva (ACG 2021; ESGE 2021).
	- **≥ 7 → melhor corte para prever terapia endoscópica** (S 80%, E 57%; Stanley 2017).

## 🌪️ Mecanismo Fisiopatológico
- Cada variável é um marcador indireto de **volume perdido** ou de **reserva para tolerá-lo**:
	- Ureia alta → sangue digerido no delgado + hipovolemia
	- Hb baixa → perda já diluída
	- PAS baixa e taquicardia → perda em curso
	- Melena e síncope → volume exteriorizado
	- Hepatopatia e IC → menor reserva fisiológica

---

## 🎯 PODER DIAGNÓSTICO (O PIVÔ)
- **Significado Clínico:** um GBS **0–1** muda a conduta de "internar e esperar a EDA" para "alta com EDA ambulatorial" em [[Hemorragia Digestiva Alta Não Varicosa]].
- **Acurácia (LR+/LR-):**
	- GBS = 0: **LR 0,02** para necessidade de intervenção urgente (Srygley 2012).
	- GBS ≤ 1: sensibilidade de 98,6% para sobreviver sem intervenção (Stanley 2017, 3.012 pacientes).
	- Melhor que Rockall pré-EDA, Rockall completo e AIMS65 para prever **intervenção ou morte** (AUROC 0,86 × 0,66–0,70) — mas **não** é o melhor para prever só mortalidade (aí AIMS65 e PNED vão melhor) nem ressangramento.
- **Associação Clássica:** GBS 0–1 + sem lesão de alto risco + seguimento garantido = tratamento ambulatorial.

---

## ⚠️ Pitfalls e Falsos
- **Falsos Positivos:** ureia elevada por DRC ou desidratação de outra causa; Hb baixa por anemia crônica prévia.
- **Falsos Negativos:** sangramento muito recente — a Hb ainda não caiu e a ureia ainda não subiu.
- **Erro Comum de Execução:**
	- Usar o GBS como critério **suficiente** de alta. É **necessário, não suficiente**: a decisão final considera a lesão vista (ou a ver) na EDA, comorbidades e acesso a seguimento.
	- Usar o GBS para estimar mortalidade — não foi para isso que foi construído.
	- Aplicar na HDB — para hematoquezia, o escore validado é o de **Oakland** (≤ 8 → alta precoce; ACG 2023).
